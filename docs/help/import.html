Importing recordings

Got a voice memo, a Zoom recording, an old interview? Drag the audio file anywhere onto Parrot's window, or use File → Import Audio. Parrot copies the file in, transcribes the whole thing on your Mac, works out who was speaking, and then runs the same report the live calls get. It shows up as a normal meeting, filed under the file's own date rather than today, which keeps last week's recording looking like last week.

Good to know

  • Most formats work: m4a, mp3, wav, aac, caf. If it plays on a Mac, Parrot can probably eat it.
  • An imported file is one mixed track, so speaker separation leans on voice differences rather than the clean two-track split live calls get. It does a decent job, and you can rename speakers on the meeting.
  • Import waits while a live recording is running. One Whisper, one job at a time.
